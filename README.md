# Poseidon - Trading App
This application has been developed to manage financials products. You can see, add, modify and delete financials products.  
It's possible to log in as a user or as an admin.  
Credentials are available in the credentials.txt file.

## Prerequisite :

 - Java  17.0.16.1 (optional)
 - MySQL 8.4.11-0ubuntu0.26.04.1 (optional)
 - Docker 29.8.0
 - Docker Compose 5.5.1
 
## Installation :
 
#### Step 1 : download this project
 
#### Step 2 : dockerise the app
At the root's project, run the folowing command : docker compose up -d

#### Step 4 : Use your brower and go to the localhost:8087 address
Use credendials available in credentials.txt file to login.  
Enjoy testing the app :-)
